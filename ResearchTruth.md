# Research Truth

## 1. Purpose
This document is the repository's current research-truth baseline after combining governing instructions, repository evidence, prior research, and the owner's resolved scope decisions. It should be used as the active truth reference before any new theory, design, or implementation work is treated as authoritative. Unlike `ScopeDefinition.md`, which framed open questions and decision options, this file records what is currently true, what is only historical, what is inferred, what is contradicted, and what remains unknown after those questions were answered in `ScopeDecisionLog.md`. `ScopeDecisionLog.md` is incorporated here as the authoritative owner-decision layer for resolved scope choices. Facts are marked as `Confirmed`, `Owner-decided`, `Inferred`, `Contradicted`, `Unknown`, or `Historical-only` so future work does not silently promote weak or stale claims into active truth.

## 3. Truth Hierarchy
The synthesis below uses this order of authority:

1. `AgentRules.md` plus the binding `Agent*.md` appendices it invokes.
2. Explicit owner decisions in `ScopeDecisionLog.md`.
3. Direct repository implementation evidence.
   Current active-root implementation evidence outranks research claims about current behavior.
   Archived implementation evidence is authoritative for historical behavior only unless the owner adopted it.
4. Validated research synthesis and repository-backed paper notes.
5. Weaker or stale historical artifacts, including superseded research logs and backup research files.

Special note:
- `Current_State.md` and `Event_Ledger.ndjson` remain authoritative for interaction-log history when they cover an event, but they do not override later owner scope decisions recorded in `ScopeDecisionLog.md` for this synthesis.
