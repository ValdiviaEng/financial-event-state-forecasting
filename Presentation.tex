\begin{frame}{Talk Roadmap}
\begin{columns}[T]
\begin{column}{0.48\textwidth}
\textbf{Question}
\begin{itemize}
  \item Can aligned company-news event states improve multi-horizon excess-return forecasts?
  \item Can deep models help without leaking future information?
\end{itemize}
\end{column}
\begin{column}{0.48\textwidth}
\textbf{Answer}
\begin{itemize}
  \item The strongest active evidence is a tuned XGBoost event-market baseline.
  \item A frozen-TSMixer mixer improved validation but not XGBoost lockbox.
  \item The main contribution is a rigorous, reproducible evaluation system.
\end{itemize}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{Why This Is Hard}
\begin{columns}[T]
\begin{column}{0.55\textwidth}
\begin{itemize}
  \item Returns have low signal-to-noise and strong nonstationarity.
  \item News can matter, but timestamps, no-news days, and provider truncation create hidden biases.
  \item Model selection can overfit validation folds even when deep models look plausible.
\end{itemize}
\end{column}
\begin{column}{0.42\textwidth}
\begin{block}{Design principle}
Train/validation is for search. Lockbox is for one final post-selection diagnostic.
\end{block}
\begin{block}{Metric principle}
ROC-AUC is not applicable: this is continuous excess-return regression.
\end{block}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{Discussion: What I Learned}
\begin{columns}[T]
\begin{column}{0.50\textwidth}
\textbf{Positive lessons}
\begin{itemize}
  \item Reproducibility can be engineered through manifests, saved predictions, and tests.
  \item Tree baselines are hard to beat in small financial tabular settings.
  \item Deep sequence models need architecture audits and strong baselines.
\end{itemize}
\end{column}
\begin{column}{0.48\textwidth}
\textbf{Cautions}
\begin{itemize}
  \item Validation improvement did not guarantee lockbox improvement.
  \item Stale TSMixer readout invalidated earlier deep evidence.
  \item Portfolio-looking plots can mislead without transaction realism and causal validation.
\end{itemize}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{Final Conclusion}
\begin{block}{Scientific conclusion}
The updated XGBoost event-market pipeline is the current strongest artifact-backed evidence, but event-state value and deep-sequence superiority are not proven.
\end{block}
\begin{block}{Deep learning conclusion}
For financial forecasting, the most important DL competence is not just adding BERT, TSMixer, or Transformers; it is controlling leakage, validating architecture semantics, and resisting overfit narratives.
\end{block}
\begin{block}{Non-claim boundary}
No live forecast, no trading advice, no benchmark-comparability promotion, and no Stage 6 reinterpretation.
\end{block}
\end{frame}

\begin{frame}{Likely Q\&A}
\small
\begin{itemize}
  \item \textbf{Why no AUC?} Labels are continuous excess returns; classification AUC would require an extra directional label and a different objective.
  \item \textbf{Why not claim the portfolio result?} It is historical, frictionless, post-selection, and partly uses stale/frozen TSMixer diagnostic predictions.
  \item \textbf{Where is deep learning?} FinBERT sidecars, TSMixer sequence modeling, horizon mixing, and comparison to modern time-series architectures; the project also shows why DL claims need robust validation.
  \item \textbf{What would improve next?} Corrected TSMixer rerun, stronger event encoders, larger universe as a new benchmark family, and cost-aware portfolio diagnostics.
\end{itemize}
