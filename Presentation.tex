\begin{frame}{Talk Roadmap}
\begin{columns}[T]
\begin{column}{0.48\textwidth}
\textbf{Question}
\begin{itemize}
  \item Can aligned company-news event states improve multi-horizon excess-return forecasts?
  \item Can deep models help without leaking future information?
\end{itemize}
\end{column}
\begin{column}{0.48\textwidth}
\textbf{Answer}
\begin{itemize}
  \item The strongest active evidence is an optimal model XGBoost event-market baseline.
  \item The optimal mixed model (frozen-base horizon mixer) improved validation but not optimal model XGBoost lockbox.
  \item The main contribution is a rigorous, reproducible evaluation system.
\end{itemize}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{Why This Is Hard}
\begin{columns}[T]
\begin{column}{0.55\textwidth}
\begin{itemize}
  \item Returns have low signal-to-noise and strong nonstationarity.
  \item News can matter, but timestamps, no-news days, and provider truncation create hidden biases.
  \item Model selection can overfit validation folds even when deep models look plausible.
\end{itemize}
\end{column}
\begin{column}{0.42\textwidth}
\begin{block}{Design principle}
Train/validation is for search. Lockbox is for one final post-selection diagnostic.
\end{block}
\begin{block}{Metric principle}
ROC-AUC is not applicable: this is continuous excess-return regression.
\end{block}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{Discussion: What I Learned}
\begin{columns}[T]
\begin{column}{0.50\textwidth}
\textbf{Positive lessons}
\begin{itemize}
  \item Reproducibility can be engineered through manifests, saved predictions, and tests.
  \item Tree baselines are hard to beat in small financial tabular settings.
  \item Deep sequence models need architecture audits and strong baselines.
\end{itemize}
\end{column}
\begin{column}{0.48\textwidth}
\textbf{Cautions}
\begin{itemize}
  \item Validation improvement did not guarantee lockbox improvement.
  \item Portfolio-looking plots can mislead without transaction realism and causal validation.
  \item Data compilation is a bottleneck: API limits (25 calls/day) slow dataset refresh; webscraping is advised to expand coverage.
\end{itemize}
\end{column}
\end{columns}
\end{frame}

\begin{frame}{Final Conclusion}
\begin{block}{Scientific conclusion}
The optimal model XGBoost event-market pipeline is the current strongest artifact-backed evidence, but event-state value and deep-sequence superiority are not proven.
\end{block}
\begin{block}{Deep learning conclusion}
For financial forecasting, the most important DL competence is not just adding BERT, optimal model TSMixer, or Transformers; it is controlling leakage, validating architecture semantics, and resisting overfit narratives.
\end{block}
\begin{block}{Performance and simulation conclusion}
Performance gains are modest and fragile across horizons, and portfolio simulations remain diagnostic-only; the strongest evidence is the optimal model XGBoost lockbox deltas, not the historical portfolio curves.
\end{block}
