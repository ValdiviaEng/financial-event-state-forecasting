## 7. v1p0 Stage Flow

| Stage | Intent | Inputs | Outputs | Stop conditions |
| --- | --- | --- | --- | --- |
| Sanitization | Make active docs consistent with v1p0. | Current docs and decisions. | Updated root docs and guidebook. | Missing preservation approval or unresolved contradiction. |
| Structure planning | Decide exact source/config/test layout. | Architecture map and guidebook. | Planned file list and contracts. | Unknown imports or active/deprecated code confusion. |
| Manifest slice | Create version and registry contracts. | v1p0 naming. | Manifest/config schemas. | Any attempt to relabel v0p9 artifacts. |
| Feature slice | Define/build market lag sidecars. | Clean row universe and market data contracts. | Feature artifacts. | Leakage or row mismatch. |
| Baseline slice | Implement lag-linear and fixed XGBoost dependency path. | Features, splits, labels. | Lag-linear smoke predictions; XGBoost blocker if dependency absent. | Lockbox tuning, fold-local preprocessing failure, or missing XGBoost dependency for full XGBoost predictions. |
| Diagnostic slice | Add strata and uncertainty evidence. | Predictions, labels, flags. | Diagnostic artifacts. | Missing provenance or overfit checks. |
| Report clarity slice | Refactor report wording/tables. | Diagnostic and prediction outputs. | Static report packet. | Report/data mismatch or unsupported claims. |
