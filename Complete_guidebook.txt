### Stage 6 Result Meaning

The strict market hurdles selected by the frozen validation rule are `market_elastic_net` for `1d`, `10d`, `20d`, and `60d`, and `market_ridge` for `5d`. The event-state gated fusion model did not clear the predeclared short-horizon primary hurdle because it improved on both mean squared and mean absolute loss deltas in `0/3` primary horizons in validation and `0/3` in lockbox.

The comparability record has no invalidating reasons, but it remains limitation-bearing for three reasons: Alpha Vantage provider-level article completeness is not claimed, an active split-adjustment method is not selected while Stage 2 uses a derived manifest only, and the train-validation gap diagnostic is blocked because Stage 5 saved no train predictions.

What the deprecated guidebook does better:

- Provides a detailed file-by-file format.
- Includes clear per-file roles, implementation notes, and test notes.
- Includes implementation-level function and module coverage for the historical snapshot.
- Offers a practical example of a guidebook as a working repository map.

What the old active skeleton guidebook did worse before this upgrade:

- It grouped most scaffold files by directory rather than listing every active file.
- It did not list planned functions, planned config sections, or planned test targets.
- It did not include coverage counts or guidebook audit checks.
- It did not include an explicit active-vs-deprecated comparison.

What the deprecated guidebook does worse or dangerously:

- It reflects a historical snapshot, not the active root.
- It treats Finnhub-era assumptions and legacy code paths as historical implementation reality.
- It includes paths and executable modules that do not exist as active implementation in this root.
- It can tempt accidental reactivation of archive claims, static company KB behavior, uncertainty-aware defaults, and richer model branches outside phase 1.
- It lacks the current AgentRules interaction-log and approval-gate discipline.

Mixed approach adopted here:

- Borrow the deprecated guidebook's detailed per-file style, status legend discipline, implementation-note discipline, test-note discipline, and practical inventory approach.
- Use only active-root truth from `AgentRules.md`, `ProjectDefinition.md`, `ScopeDecisionLog.md`, `ResearchTruth.md`, active docs, active scripts, active data evidence, and generated scaffold comments.
- Reject deprecated implementation status claims, provider assumptions, active path claims, static-KB phase-1 claims, uncertainty defaults, and archive-as-active behavior.
- Preserve guidebook role as a map, not an authority source.
