\begin{abstract}
This project studies whether aligned company-news event states improve multi-horizon excess-return forecasting beyond strong market baselines. I built a local, reproducible artifact pipeline for the top-50 liquid U.S. equities, with same-day-as-close news alignment, no-news states, purged expanding folds, an untouched lockbox, fold-local preprocessing, saved predictions, tuning ledgers, and conservative claim gates. The strongest current active model is an optimal model XGBoost configuration: 800 development trials produced a post-selection lockbox weighted error delta of $-5.34\times10^{-4}$ versus the prior XGBoost baseline. An optimal mixed model (frozen-base horizon mixer) improved validation error, but degraded versus optimal model XGBoost on lockbox, illustrating selection pressure. A historical portfolio simulation is reported only as a diagnostic. The main conclusion is methodological: in noisy financial forecasting, leakage control and non-claiming uncertainty analysis are as important as model complexity.
\end{abstract}

\section{Introduction}
Financial news may contain useful short-lived information, but return prediction is low signal-to-noise and highly vulnerable to leakage, multiple testing, and post-hoc trading narratives. The project therefore frames the task as end-of-day forecasting of forward excess returns for horizons $\{1,5,10,20,60\}$ days, not as price prediction or trading advice. The contribution is a reproducible deep-learning-ready benchmark: top-50 equities, Alpha Vantage news, Twelve Data OHLCV, explicit no-news rows, purged walk-forward development folds, a final lockbox, and artifact-backed model comparisons. The implemented roster spans linear and tree market baselines, FinBERT feature sidecars, TSMixer sequence diagnostics, optimal model XGBoost tuning, and horizon-level XGBoost/TSMixer mixing. AUC is intentionally not reported: the target is continuous excess return, so RMSE/MAE, zero-baseline $R^2$, rank IC, bootstrap support, and lockbox deltas are the relevant metrics.

\section{Related Work}
The design follows market-efficiency and asset-pricing cautions from Fama, Fama-French, and Campbell-Lo-MacKinlay \cite{Fama1970,FamaFrench1993,Campbell1997}: small apparent edges require strict out-of-sample controls. Textual-finance work shows why news can matter but also why representation matters \cite{Tetlock2007,LoughranMcDonald2011}. Modern NLP motivates contextual encoders and FinBERT-style finance adaptation \cite{Devlin2019BERT,Araci2019FinBERT}. For tabular market features, gradient boosting remains a strong baseline \cite{ChenGuestrin2016,Ke2017LightGBM}. For sequence modeling, the relevant state of the art includes interpretable multi-horizon attention, patch-based transformers, inverted transformers, and foundation time-series models \cite{Lim2021TFT,Nie2023PatchTST,Liu2024iTransformer,Ansari2024Chronos}. Evaluation follows forecasting-metric and time-series validation guidance \cite{HyndmanKoehler2006,Bergmeir2018}; multiple-testing caution follows Harvey et al. \cite{Harvey2016}. ROC-AUC is cited only to justify exclusion for this regression target \cite{Fawcett2006}.

\section{Experiments}
\textbf{Data and splits.} The benchmark uses 50 liquid equities, five horizons, forward leave-one-out excess-return labels, and explicit event-state rows for no-news dates. The enhanced Alpha Vantage rebuild aligned 166,711 news rows while preserving provider-truncation limitations. Stage 4 defines nine expanding walk-forward development folds plus a held-out lockbox ending 2026-02-13; lockbox rows are never used for tuning.

\textbf{Models and training.} The main tuned model is the optimal model XGBoost event-market candidate, selected from 800 Optuna trials by a guarded validation objective over RMSE/MAE horizon deltas. The TSMixer branch exposed a readout bug: prior mean-time pooling was stale; the corrected readout is flattened time-feature state. Because a corrected full TSMixer search was estimated at 23.1 hours and was rejected, the optimal mixed model (frozen-base horizon mixer) tuned only a lightweight horizon mixer over frozen optimal model XGBoost and frozen optimal model TSMixer predictions; no TSMixer weights were retrained.

\textbf{Results.} Figure~\ref{fig:main} shows the key pattern. Optimal model XGBoost improved against the prior XGBoost family on lockbox, but the optimal mixed model (frozen-base horizon mixer) is a cautionary counterexample: it improved validation and the frozen optimal model TSMixer diagnostic input, yet was worse than optimal model XGBoost on lockbox. Block-bootstrap evidence was supportive for the earlier frozen XGBoost candidate, but final claim gates remain conservative.

\section{Discussion}
The strongest lesson is that financial deep learning must be evaluated as a system, not as a model leaderboard. The project found real engineering gains: leakage-aware splits, saved predictions, uncertainty diagnostics, tuning traces, and stronger market baselines. It also found failure modes: validation-to-lockbox degradation and portfolio-like diagnostics that can look persuasive while remaining non-causal and assumption-dependent. A practical bottleneck remains data compilation: API limits (25 calls/day) slow dataset refresh, so webscraping is advised to expand coverage. The transparent conclusion is therefore narrow: the optimal model XGBoost pipeline is the current strongest active evidence; the optimal mixed model (frozen-base horizon mixer) did not earn a positive lockbox claim; event-state value is not proven; and all outputs remain historical diagnostics, not live forecasts or trading signals.
