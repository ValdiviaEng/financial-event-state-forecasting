\begin{abstract}
This project studies aligned company-news event states for multi-horizon excess-return forecasting beyond strong market baselines. I built a local, reproducible artifact pipeline for the top-50 liquid U.S. equities, with same-day-as-close news alignment, no-news states, purged expanding folds, an untouched lockbox, fold-local preprocessing, saved predictions, and tuning ledgers. The primary XGBoost configuration completed 800 development trials and is the strongest lockbox error model: weighted error improved by $-5.34\times10^{-4}$ versus the prior XGBoost baseline with a 62.2\% both-metric improvement rate. TSMixer is the strongest lockbox portfolio-ranking model, reaching 15.05\% over the 137-day lockbox simulation. The Mixed model improved validation by $-2.97\times10^{-4}$ versus XGBoost, but worsened lockbox error by $+9.20\times10^{-5}$. The result is objective-specific: XGBoost wins calibrated error forecasting, while TSMixer wins ranking-driven portfolio simulation.
\end{abstract}

\maketitle

\section{Introduction}
Financial news may contain useful short-lived information, but return prediction is low signal-to-noise and highly vulnerable to leakage, multiple testing, and post-hoc narratives. The project therefore frames the task as end-of-day forecasting of forward excess returns for horizons $\{1,5,10,20,60\}$ days. The contribution is a reproducible deep-learning-ready benchmark: top-50 equities, Alpha Vantage news, Twelve Data OHLCV, explicit no-news rows, purged walk-forward development folds, a final lockbox, and artifact-backed model comparisons. The implemented roster spans linear and tree market baselines, FinBERT feature sidecars, TSMixer sequence models, XGBoost tuning, and horizon-level XGBoost/TSMixer mixing. AUC is intentionally not reported: the target is continuous excess return, so RMSE/MAE, zero-baseline $R^2$, rank IC, bootstrap support, and lockbox deltas are the relevant metrics.

\section{Related Work}
The design follows market-efficiency and asset-pricing principles from Fama, Fama-French, and Campbell-Lo-MacKinlay \cite{Fama1970,FamaFrench1993,Campbell1997}: small apparent edges require strict out-of-sample controls. Textual-finance work shows why news can matter but also why representation matters \cite{Tetlock2007,LoughranMcDonald2011}. Modern NLP motivates contextual encoders and FinBERT-style finance adaptation \cite{Devlin2019BERT,Araci2019FinBERT}. For tabular market features, gradient boosting remains a strong baseline \cite{ChenGuestrin2016,Ke2017LightGBM}. For sequence modeling, the relevant state of the art includes interpretable multi-horizon attention, patch-based transformers, inverted transformers, and foundation time-series models \cite{Lim2021TFT,Nie2023PatchTST,Liu2024iTransformer,Ansari2024Chronos}. Evaluation follows forecasting-metric and time-series validation guidance \cite{HyndmanKoehler2006,Bergmeir2018}; multiple-testing control follows Harvey et al. \cite{Harvey2016}. ROC-AUC is cited only to justify exclusion for this regression target \cite{Fawcett2006}.

\section{Experiments}
\textbf{Data and splits.} The benchmark uses 50 liquid equities, five horizons, forward leave-one-out excess-return labels, and explicit event-state rows for no-news dates. The enhanced Alpha Vantage rebuild aligned 166,711 news rows while preserving provider-truncation limitations. The split protocol defines nine expanding walk-forward development folds plus a held-out lockbox from 2025-09-30 to 2026-02-13; lockbox rows are never used for tuning.

\textbf{Model-selection rationale.} The model roster was chosen to separate three questions. First, XGBoost is a strong tabular baseline for sparse market/event features and gives a high bar for calibrated return-level prediction. Second, TSMixer tests whether a 60-day sequence representation can extract temporal structure that a same-row tree model misses. Third, the Mixed model asks whether frozen XGBoost and TSMixer predictions can be combined horizon by horizon without retraining the sequence model. I also built a contextual bandit ranking protocol because the downstream use case is naturally cross-sectional: choose top and bottom baskets, not just minimize pointwise error. That protocol used combined feature and prediction contexts, primary $k=5$, $\epsilon=0.05$, 47,250 context rows, and 374,220 selection rows; it guided the ranking-family roadmap while the final comparison here is XGBoost, TSMixer, and the Mixed model.

\textbf{Models and training.} XGBoost is the primary event-market candidate, selected from the full 800-trial Optuna search. The selected trial used 21 features: seven market OHLCV and intraday variables, aligned-news/provider flags, minutes since latest aligned article, eight event-state hash embeddings, and no-news/empty-state flags. Its tree configuration is deliberately small and regularized: 200 histogram trees, depth 2, learning rate 0.0403, subsample 0.987, column subsample 0.543, $\gamma=0.502$, $\alpha=7.74$, and $\lambda=0.151$. The TSMixer incumbent is trial 307 from the sequence branch: 60-day windows, 21 features, two-seed mean, 10 epochs, batch size 2048, four mixer blocks, hidden widths 32/384/32, dropout 0.2, learning rate 0.00401, and 83,017 parameters. The Mixed model is an 800-trial frozen-base horizon mixer over XGBoost and TSMixer predictions; no TSMixer weights were retrained.

\textbf{Results.} Figure~\ref{fig:main} shows the key pattern. XGBoost is the strongest active model on lockbox error metrics: per-horizon RMSE is 0.0214, 0.0468, 0.0661, 0.0943, and 0.1929 for 1d, 5d, 10d, 20d, and 60d respectively (Appendix Table~\ref{tab:lockbox_horizon_results}). TSMixer is the strongest lockbox ranking model in the portfolio simulation: every best-by-horizon portfolio row is TSMixer, including 15.05\% at 1d and 12.43\% at 60d (Appendix Table~\ref{tab:portfolio_horizon_results}). The fuller model and horizon simulation table shows why this is not a contradiction: XGBoost dominates calibrated RMSE and MAE, but its 1d/5d ranking simulations stay at the initial capital with zero trades, whereas TSMixer creates useful ranked baskets across all horizons (Appendix Table~\ref{tab:portfolio_model_horizon_results}). The Mixed model improved validation fit but did not beat XGBoost on lockbox error. Thus, error forecasting and cross-sectional ranking produce different winners.

\section{Discussion}
The strongest lesson is that financial deep learning must be evaluated as a full forecasting system, not as an isolated model leaderboard. XGBoost is the best calibrated error forecaster because it improves the prior XGBoost lockbox weighted error and clears more than half of RMSE/MAE comparisons. Its shallow, strongly regularized trees are well matched to robust point prediction, but that same shrinkage can compress cross-sectional dispersion. TSMixer is the best ranking forecaster because its sequence predictions translate most strongly into lockbox portfolio simulations. The likely mechanism is objective mismatch: RMSE and MAE reward accurate return levels, while the portfolio simulation rewards relative ordering among names on each rebalance date. A sequence model can be worse in absolute error while still placing the better candidates higher in the cross-section. The Mixed model adds scientific value by showing that strong validation performance does not automatically translate to lockbox performance. Next steps are to try a deeper reinforcement learning model with capacity to rank predictions from most probable to least probable, expand data collection beyond the 25 API calls per day bottleneck, and add transaction costs for richer portfolio evaluation. The project therefore produces a strong excess-return forecasting benchmark, an objective-specific model conclusion, and a concrete roadmap for improving the next model family.
