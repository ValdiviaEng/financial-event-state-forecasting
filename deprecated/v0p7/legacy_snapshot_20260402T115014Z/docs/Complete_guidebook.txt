- It documents where each project-maintained file lives, what it currently contains, and what its comments/docstrings say it is supposed to do.

- Excluded by request: `.env`.

Legend
- State: implemented = contains working code now.
- State: blueprint = mostly comments/docstrings and structure, little or no business logic yet.
- State: mixed = has some real logic but is still incomplete.
